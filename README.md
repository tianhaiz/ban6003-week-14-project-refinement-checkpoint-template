# BAN 6003 Week 14: Final Report Clinic

**BAN 6003: Data Management and Analytics Integration**  
**Week 14 GitHub Template**

**This clinic is not graded.** It replaces the Week 14 lab. Nothing in this repository is submitted or scored.

## Purpose

The clinic helps you find and fix common final-report problems before the final project submission. It follows the Module 14 themes: business meaning, use boundaries, project story, interpretation, ethics, and recommendations.

The notebook `notebooks/module14_final_report_clinic.ipynb` contains:

1. How to use this clinic
2. Common report problems and how to fix them (8 short, runnable demos)
3. A worked report audit: a made-up weak report section, an audit against the final project rubric categories, and a revised version
4. Repository organization, a README template, and a **self-check cell** you can copy into your own project
5. Final submission reminders that match the Canvas page "BAN 6003 Final Project Submission"

## How to Use

- Optional, but strongly recommended. Plan about 1.5-2 hours.
- Keep this notebook open next to your own final project repository. After each demo, check your own report for the same problem.
- No answers are required. Every code cell already runs; the whole notebook runs in well under a minute.
- Copy the self-check cell from Part 4 into your project. It checks the required files, the HTML report, large files, `.env`, and the AI Use Disclosure cell.

## Data

No local data files are required. The demos use the `nycflights13` package and a few small made-up tables.

## How to Work

1. Create your own GitHub repository from this template, or simply open it in a Codespace.
2. You can work in GitHub Codespaces or in local VS Code. On the UTSA campus network Codespaces may not connect; use the local setup there (see the Canvas page on local setup).
3. Install dependencies with `python -m pip install -r requirements.txt` if working locally.
4. Open `notebooks/module14_final_report_clinic.ipynb` and run the cells from top to bottom.
5. Use what you learn to revise your final project repository.

There is nothing to submit for this clinic. Your final project is submitted separately through the Canvas assignment "BAN 6003 Final Project Submission".
